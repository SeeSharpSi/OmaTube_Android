Nerd Fonts - added glyphs and patcher source code
https://github.com/ryanoasis/nerd-fonts

The bundled JetBrainsMonoNerdFont files are JetBrains Mono patched with the
Nerd Fonts Patcher. The base JetBrains Mono font is covered by the SIL Open
Font License in jetbrains-mono-OFL.txt. The Nerd Fonts project adds glyphs and
ships source code under its own terms, summarized here and in
nerd-fonts-glyph-sources.txt.
